DIY Cupboards AI – First Working Version

Status:
- FastAPI server runs
- /chat endpoint works
- static index.html shows chat UI
- messages go from browser → backend → reply

How to run:
1. cd diy-cupboards-ai
2. .venv\Scripts\activate
3. uvicorn main:app --reload
4. open http://127.0.0.1:8000/
